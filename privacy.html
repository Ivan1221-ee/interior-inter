Политика конфиденциальности

Inter — учебный проект сайта студии дизайна интерьеров. Эта политика описывает работу демонстрационных форм и сайта.

Данные в формах

Формы предлагают указать имя и номер телефона для консультации по дизайн-проекту. В текущей версии введённые сведения проверяются в браузере. Отправка и хранение заявок на сервере не подключены. Для проверки формы используйте вымышленные данные.

Данные при посещении сайта

Страницы размещены на GitHub Pages. Информация о том, как GitHub обрабатывает данные посетителей, доступна в заявлении о конфиденциальности GitHub.

Контакты

В макете указан адрес студии Inter: Санкт-Петербург, ул. Ленина, д. 89, офис 12. Адрес и контактные данные на главной странице приведены для демонстрации.
